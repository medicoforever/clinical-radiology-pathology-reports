# Clinical Radiology Atlas - Pathology Reports Corpus

A curated, comprehensive clinical radiology reports repository extracted from Centricity RIS-i (2.12M+ clinical reports database).
Organized by organ systems, anatomical compartments, imaging modalities, and clinical pathologies with full boolean search metadata.

---

## Repository Structure

- `FEEDBACK.md`: User feedback log & instructions.
- `PROGRESS.md`: Real-time extraction progress, statistics, and subspecialty metrics.
- `TAXONOMY.md`: Complete index and directory tree of all extracted pathology files.
- `reports/`:
  - `neuroimaging/`: Brain, skull base, orbit, temporal bone, cerebrovascular pathologies.
  - `head_and_neck/`: Sinonasal, pharynx, larynx, salivary glands, lymph nodes.
  - `spine/`: Cervical, thoracic, lumbar, spinal cord, disc and osseous pathologies.
  - `thoracic/`: Lungs, pleura, mediastinum, airway, thoracic vascular.
  - `cardiovascular/`: Coronary, myocardial, valvular, aortic, peripheral vascular.
  - `gastrointestinal/`: Esophagus, stomach, small bowel, colon, rectum, peritoneal cavity.
  - `hepatobiliary_pancreatic/`: Liver, biliary tree, gallbladder, pancreas, spleen.
  - `genitourinary/`: Kidneys, ureters, bladder, adrenal, prostate, scrotum, uterus, ovaries.
  - `musculoskeletal/`: Upper/lower extremities, joints, bones, soft tissue tumors, trauma.
  - `pediatric_and_fetal/`: Fetal anomaly scans, neonatal neuro, pediatric body/bone.
  - `interventional_and_emergency/`: Trauma whole body, acute vascular, interventional procedures.
